Enhanced KITOS USB 3.0 SuperSpeed validation
2026-10-28 (Asia/Tokyo)

Scope:
  Extend the existing USB 2 / PCIe-VL805 / loadable C driver work in place.
  Add USB 3 Gen1 x1 (5 Gbit/s) enumeration and BOT/SCSI storage, with USB 2
  HID devices sharing the controller. No physical device was used or modified.
  Existing uncommitted work retained; no reset/checkout/clean/commit performed.

Environment:
  macOS arm64, Apple clang 21, AArch64 GCC 15.2, QEMU 10.2.2, Python 3.
  QEMU: /Users/shingo/qemu-10.2.2/bin/qemu-system-aarch64
  Independent FAT/exFAT fixtures: mtools and exfat-utils 1.4.0.

Implementation:
  Supported Protocol capabilities, opaque Slot Type, standard/custom PSI IDs.
  USB 3 root Hot/Warm Reset, recoverable Inactive/Compliance/CAS detection.
  Shared kernel/native standard enumeration: 512-byte EP0, BOS/SS capability,
    mandatory endpoint companion parsing, 1024-byte bulk MaxPacket, MaxBurst,
    interrupt interval and MaxESITPayload. U1/U2 power saving disabled.
  SS hub descriptor, SET_HUB_DEPTH, port power, U1/U2 timeout requests,
    port reset/change acknowledgement and downstream speed decoding.
  Physical root disconnect during an active TD returns ENODEV while retaining
    controller-owned DMA until Disable Slot; other ports remain operational.
  BOT reset recovery resets halted endpoints with Reset Endpoint and idle or
    stopped endpoints with Configure Endpoint Drop+Add, preserving sequence.
  C driver ABI advanced to 3 for widened EP0 size and endpoint companions.
    Kernel and every .EKM must be updated together. ABI 1/2 is rejected.

Host regression -- PASS (make test):
  SuperSpeed parser/protocol/shared enumeration/hub requests: 664 checks,
    ASan/UBSan, non-recovering. Includes malformed/truncated descriptors,
    missing/orphan companions, reserved fields, alternate settings, BOS,
    custom PSI speed ID 9 / Slot Type 7, empty protocol port groups, SS hub
    request transcript and USB 2 versus USB 3 port speed interpretation.
  Existing USB descriptor/Boot HID: 363 checks.
  BCM2711 PCIe sequence/error bounds: 1414 checks.
  Driver ELF validation/failure injection: 193164 checks across actual modules.
  FAT12/16/32/exFAT VFS: 66782 checks, ASan/UBSan; offline manual unmount added.
  BOT/SCSI: 84 checks, ASan/UBSan.
  Timer deadlines/cancel/rearm/budget/wrap: 83 checks, ASan/UBSan.
    Injected clock advance past a positive relative deadline before queuing:
    it is queued as due, without an inline callback; absolute past deadlines
    remain invalid. Prevents spurious sleep failure on a delayed QEMU vCPU.
  Existing block/FAT32/VFS/SDHCI/SD/geometry/page/boot-memory/ELF suites pass.

Limits:
  Pi 4 PCIe/VL805/PHY/power/firmware and real device interoperability unverified.
  5 Gbit/s identifies the supported link mode, not measured throughput.
  QEMU raspi4b has no PCIe/xHCI model. Full EKITOS tests run on raspi4b/DWC2;
    SS tests run the same C sources on the PC against QEMU virt PCI MMIO/DMA.
    This is not an EKITOS kernel port to virt or physical VL805 validation.
  QEMU's standard hub is USB 2. SS hub control is mock-tested; actual SS hub
    enumeration, hotplug and routing remain unverified.
  No SuperSpeedPlus 10/20 Gbit/s/multiple lanes, UAS/streams, isochronous,
    USB link power saving, camera/audio/network class drivers or all-device claim.
  Supported classes remain Boot HID and BOT/SCSI storage. SS HID packet/context
    handling is implemented but no actual SS HID device model was available.
  See usb-superspeed.md, usb-storage.md and ../sdk/README.md.
