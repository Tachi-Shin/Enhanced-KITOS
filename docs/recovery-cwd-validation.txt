Enhanced KITOS recovery shell cwd regression
Date: 2026-10-28 JST
Environment: macOS arm64, aarch64-elf-gcc 15.2, QEMU 10.2.2
Driver ABI: 5 (unchanged)

Reported physical Pi 4 symptom
  FAT32 mounted, /bin empty, kernel recovery shell active.
  cd bin stored //bin; cd .. stored //bin/.. instead of /.
  Previous normal-EL0-shell tests did not exercise recovery-shell cd.

Fix
  Add vfs_resolve_directory using existing prefix validation and mount traversal.
  Both process chdir and recovery-shell cd call it; duplicate lexical cwd logic
  has been removed. Output is committed only after a directory is validated.
  Recovery relative path join avoids introducing // at root.
  No disk formatting, user file removal or implicit shell replacement is used.
