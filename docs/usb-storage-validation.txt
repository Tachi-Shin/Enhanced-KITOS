Enhanced KITOS USB Mass Storage / FAT12/16/32 / exFAT validation

Scope:

  Add loadable C STORAGE.EKM, USB 2 bulk, BOT/SCSI block I/O, removable device
  lifetime management, automatic VFS mounts, and FAT-family/exFAT read/write.
  ABI advanced to 2 because host ops, block objects and the SDK table changed.
  No physical USB/SD device or existing user disk image was used or modified.
  No commit/reset/checkout/clean performed.

Practical limits:
  Physical Pi 4/VL805 and real storage bridges are unverified. SuperSpeed/UAS,
    CBI/UFI/CD-ROM, encrypted/TexFAT and all other USB classes remain unsupported.
  A USB 3 storage device must use a USB 2 path and expose BOT/SCSI.
  No filesystem repair/format command, RTC, journaling or power-loss atomicity.
  Fixed pools; first compatible partition only; rename does not replace an
    existing destination. Existing SD root FAT32 selection remains unchanged.
  See docs/usb-storage.md and sdk/README.md for installation and ABI 2 updates.
