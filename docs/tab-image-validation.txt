Enhanced KITOS Tab completion distribution regression
Date: 2026-10-28 JST

Cause
  build/tests/system.img retained an old /bin/sh (594712 bytes).
  SHA-256: 9cc0f53bb412ee526286fa25759d7acda7646d13b8df924946e8f317b04ba5be
  It had no sh_edit_read symbol, history text, history file path or OSC 133 marker.
  The built shell had the editor but run_image.py deliberately left existing
  images unchanged. Fresh-image tests masked this distribution discrepancy.

Change
  Add explicit make update-system-image / run_image.py --update.
  Back up the entire existing image before updating managed files. Preserve
  /etc, history, user data and custom command files. Do not format/recreate it.
  Existing-image startup reports when /bin/sh differs from the current build.
  sh --version and the startup banner identify history/Tab support.
  terminal_qemu_test --image tests a copy without restaging its executables.
