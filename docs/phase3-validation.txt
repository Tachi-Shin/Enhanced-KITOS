Fixes:
  Persistent namespace EBUSY returns to the caller instead of retrying forever
    under a resource pin; close followed by unlink can then make progress.
  Task creation exhaustion returns EAGAIN and leaves VM ownership with caller.
  VFS file pool exhaustion returns ENFILE, distinct from EMFILE and disk ENOSPC.
  Newlib sbrk rejects shrinking to zero, which is the brk-query sentinel.
  Reaper zombie publication/orphan reclamation is atomic against wait/spawn.
  Public errno constants are compile-time checked against Newlib.
  User C/assembly header dependencies and libc/libm relinking are tracked.
  QEMU transcripts are saved even on failure during the first boot.
